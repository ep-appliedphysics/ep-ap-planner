# Applied Physics M.S. Course Planner (GitHub Pages)

This folder is the **full planner** — same app as the live preview, packaged as files GitHub Pages can host.

## Publish (no command line)

1. Unzip this package if needed. You should see `index.html` at the top level.
2. On GitHub, click **New repository**. Name it something like `ap-ms-planner`. Keep it public (Pages is simplest that way).
3. Open the new repo → **Add file** → **Upload files**.
4. Drag in **every file and folder** from this package (`index.html`, `assets`, `favicon.svg`, `.nojekyll`, `404.html`).
5. Commit.
6. **Settings** → **Pages** → **Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: `main` (or `master`) / `/ (root)`
   - Save
7. After a minute, open the URL GitHub shows, usually:

   `https://YOUR-USERNAME.github.io/ap-ms-planner/`

8. In Canvas, add a button that opens that URL in a new tab.

## Notes

- Students should bookmark the page. Plans save in the browser.
- Export HTML / JSON / PDF still works from the Export menu.
- Re-upload these files to update the live planner.
